# Code of Conduct

## Our commitment

This is a personal portfolio project. While public contributions are not actively sought, anyone who interacts with this repository — through issues, comments, or any other channel — is expected to do so respectfully and in good faith.

## Expected behaviour

- Use welcoming and professional language
- Be respectful of differing viewpoints and creative approaches
- Provide constructive feedback when relevant
- Show courtesy toward the project owner and any community members

## Unacceptable behaviour

- Harassment, trolling, or personal attacks of any kind
- Posting others' private information without consent
- Spamming issues or pull requests
- Any conduct that would be considered inappropriate in a professional setting

## Enforcement

Interactions that violate this code of conduct may be removed, and the user may be blocked from further interaction with this repository, at the discretion of the project owner.
