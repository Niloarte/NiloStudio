# Security Policy

## Supported versions

This is a personal portfolio project. Only the latest version of the live site is actively maintained.

| Version | Supported |
|---------|-----------|
| Latest (main branch) | ✅ |
| Older / archived | ❌ |

## Reporting a vulnerability

This is a personal, non-commercial portfolio site. However, responsible disclosure is appreciated.

If you discover a security vulnerability — such as exposed credentials, an XSS issue, or a misconfigured server — please:

1. **Do not** open a public GitHub issue
2. **Email directly:** [niloarte@hotmail.com](mailto:niloarte@hotmail.com)
3. Include a brief description of the issue and steps to reproduce it

I will acknowledge your report within **72 hours** and work to address it as quickly as possible.

Thank you for helping keep this project safe.
