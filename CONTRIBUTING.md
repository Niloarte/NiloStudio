# Contributing

Thank you for your interest in NiloStudio.

This is a personal portfolio project and is **not open to external contributions** at this time. The codebase reflects specific creative and technical decisions made for a single author's use.

## What this means

- Pull requests from external contributors will generally not be accepted
- Feature requests and suggestions may be considered but are not guaranteed
- Forking for personal learning is permitted under the terms of the [LICENSE](LICENSE)

## Found a bug or issue?

If you notice a technical problem with the live site (broken links, display errors, etc.), you're welcome to open an issue describing what you found. Please include:

- A brief description of the problem
- The URL or section of the site where it occurs
- Your browser and device (if relevant)

## Security issues

Please do **not** open public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md) for responsible disclosure instructions.
